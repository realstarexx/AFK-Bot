
### Setup
Requires Node.js 18 or newer.

```bash
npm install
npm start
````

Edit `config.yml` before starting, or provide secrets through environment variables.

* `AUTH_PASSWORD` — Authentication password
* `DISCORD_WEBHOOK_URL` — Discord webhook URL
* `PORT` — Status server port (default: `5000`)
* `PUBLIC_URL` — Public deployment URL for automatic self-pinging

### Console
` say <text>` · `cmd <command>` · `status` · `reconnect`

On Aternos, enable cracked mode and install ViaVersion, ViaBackwards, and ViaRewind if the server version differs from the bot.
